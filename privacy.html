Privacy Policy

Dennis Assistant is a private application used only by its owner. It has no other users.

Data accessed: with the owner's consent, the application reads Gmail messages, creates email drafts, and reads and manages Google Calendar events.

Purpose: this data is used solely to provide personal assistant functions to the owner, such as summaries, draft replies and scheduling.

Storage and processing: data is stored on a private server in Switzerland and processed via the Anthropic Claude API to generate responses. It is not sold, shared for advertising, or disclosed to any other party.

Google API data: the application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access: access can be revoked at any time at myaccount.google.com/permissions.
